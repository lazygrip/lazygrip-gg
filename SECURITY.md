# Security

If you've found a security problem in LazyGrip.net, please report it privately instead of opening a public issue or posting it in Discord, because a public report hands the details to everyone before there's been any chance to fix it.

The way to do that is GitHub's private vulnerability reporting. Go to the Security tab of this repository, choose Report a vulnerability, and fill in the form, or use this direct link: https://github.com/lazygrip/lazygrip-gg/security/advisories/new. Only the maintainers can see what you send, and the conversation stays on that page until the problem is fixed and disclosed.

A useful report says what you found, where you found it (the page, the request, or the file and line), the steps to make it happen, and what you think an attacker could do with it. A screenshot or a short description is plenty, and you don't need a polished write-up or a working exploit.

This covers the LazyGrip.net website, its accounts and sequences, and the code in this repository. It does not cover the GRIP-EMS addon itself, which is a separate project with its own maintainers, and it does not cover other people's sequences or comments as content (use the report buttons on the site for those). Please don't test against other users' accounts or data, don't try to take the site down, and don't go digging through anything beyond what you need to show the problem is real.

LazyGrip is a small community project run by volunteers, so there's no bug bounty and no guaranteed turnaround, but every private report gets read and the people who send them get credited in the fix if they'd like to be.
